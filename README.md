# tokaido-walk-log

東海道五十三次を歩きながら、地図とGPSログを少しずつ残していくための小さなWebアプリです。

## 使い方

GitHub Pagesで公開したURLをスマホで開きます。

1. 位置情報を許可します。
2. `記録開始` を押します。
3. 歩き終えたら `停止` を押します。
4. 必要に応じて `GPXを書き出し` または `JSONを書き出し` で保存します。

## データについて

歩いた軌跡とメモは、まずブラウザのローカル保存に記録されます。GitHub Pagesに公開しても、歩行ログそのものが自動でGitHubへ送信されることはありません。
